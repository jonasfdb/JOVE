# JOVE - jonasfdb's OPM Volumetric Enhancements

[![For - 1.12.5](https://img.shields.io/badge/For-1.12.5-2ea44f)](https://)

JOVE is a set of configurations that bring amazing Volumetric Clouds to all of the outer planets of the famous OPM mod. I also included configs that add aurorae in the style of SPVE to the planets, and created new color maps for the planets based on their real-world analogs.

This is the source code repository for JOVE. You can install it via the Releases, or from [SpaceDock](https://spacedock.info/mod/4273/JOVE%20-%20jonasfdb's%20OPM%20Volumetric%20Enhancements). For more information, visit the [KSP forum thread](https://forum.kerbalspaceprogram.com/topic/230708-112x-jove-jonasfdbs-opm-volumetric-enhancements-v01-a-volumetrics-config-pack-for-the-opm-mod/).

Installation is standard. Pick a release from the side, extract it, copy the GameData folder into your KSP root directory, and enjoy. JOVE requires Blackrack's Volumetric Clouds and SPVE to both be installed. JOVE is compatible to, and was designed to be played with Astronomer's Visual Pack, which I heavily recommend you install!

Lastly, a brief note about this repository. The main branch is that of the last stable release, the develop branch gets continously updated as I work on the mod. You can (but should not, if you value the looks of your game!) use the files from that branch to check out what is basically beta versions.

Enjoy!
